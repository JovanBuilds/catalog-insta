      Arquitectura propuesta

      Cliente ligero en Unity comunicándose por WebSockets para sincronizar movimientos y ataques. Las acciones persistentes (guardado de base, progreso de era, héroes desbloqueados) viajarían vía REST al backend NestJS/Node.js con base de datos NoSQL. Esta demo reproduce la lógica de tablero y el loop de combate con JavaScript puro para validar el diseño.
