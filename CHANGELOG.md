# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [1.0.0] - 2025-11-22

### Agregado
- ✨ Catálogo público de productos con diseño inspirado en Mercado Libre
- ✨ Panel de administración con autenticación
- ✨ CRUD completo de productos (crear, leer, actualizar, eliminar)
- ✨ Filtros por categoría en el catálogo
- ✨ Integración directa con WhatsApp por producto
- ✨ Botón de WhatsApp general en el header
- ✨ Diseño mobile-first responsive
- ✨ Animaciones y transiciones suaves
- ✨ Almacenamiento en JSON
- ✨ API REST completa
- ✨ Configuración de tienda (nombre, logo, descripción, WhatsApp)
- ✨ Sistema de activación/desactivación de productos
- 📚 Documentación completa (README, guías, ejemplos)
- 📚 Guía de inicio rápido
- 📚 Ejemplos de productos
- 🔧 Configuración con variables de entorno
- 🔧 GitHub Actions para CI
- 📄 Licencia MIT

### Características Técnicas
- Backend: Node.js + Express
- Frontend: HTML5 + CSS3 + JavaScript Vanilla
- Base de datos: JSON file
- Autenticación: Header-based
- Sin frameworks pesados
- Optimizado para despliegue en Render, Railway, Heroku
